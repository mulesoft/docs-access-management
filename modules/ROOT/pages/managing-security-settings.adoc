= Managing Security Settings

Configure organization-wide security controls in Anypoint Platform to protect access and reduce risk. Enforce multi-factor authentication, restrict sign-ins by IP address, and allowlist trusted domains to meet compliance requirements. Use centralized controls to harden account security for all users and integrations.
